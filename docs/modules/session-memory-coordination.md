# Session 记忆协调模块

## 1. 当前责任

本模块接收 Pi 集成提供的会话事实，在任何内容进入长时记忆或从中读取前，统一执行 session 身份、当前 branch 路线和来源确认。它协调本地来源归档与派生索引生命周期，并为召回模块提供当前路线来源和权威展开；不生成派生记忆、不执行 OpenViking IO，也不决定相关性排序。

跨模块流程见 [`../system/source-archiving.md`](../system/source-archiving.md) 与 [`../system/source-recall.md`](../system/source-recall.md)。

## 2. 输入、状态与不变量

协调实例固定属于一个已持久化 Pi session，并持有该 session ID 与 session file。每次操作接收当前路线快照：session ID、session file、leaf ID，以及从根到 leaf 的原始条目。

必须同时满足：

1. 快照身份与协调实例完全一致；
2. 条目 ID 唯一，首条目的 `parentId` 为 `null`，后续条目逐项指向前一条；
3. 非空路线的末条目 ID 等于 leaf ID；空路线只能对应空 leaf；
4. 完整工具结果只能来自当前路线中的 `toolResult` message；
5. 列出和展开只能返回当前快照中仍存在的 entry ID；
6. 归档副本与同 ID 的 Pi 权威 entry 必须完全一致。

任一条件不成立时拒绝操作，不以本地或 OpenViking已有数据修补 Pi 当前状态。

## 3. 对外能力与边界

当前提供：

- 验证并归档当前路线；
- 把已确认来源的完整工具结果交给长时记忆；
- 按当前路线顺序列出来源副本；
- 将一个归档 entry 展开为当前 Pi 权威条目；
- 合并同一路线的普通后台索引任务；
- 为显式搜索提供调用后启动的完整同步屏障，并取消无人等待的过期任务。

本模块不解析任务语义，不选择存储或索引格式，不直接调用 OpenViking，不决定模型输入，也不维护独立 branch 身份。它通过调用方提供的索引执行函数治理时序、等待、取消和 shutdown；召回模块只能在它确认的当前来源集合中解释外部候选。

## 4. 失败与恢复

身份或路线不合法属于拒绝，不进入长时记忆。存储错误向 Pi 集成返回失败，由集成边界降级；协调模块不吞掉错误并伪装成功。

归档以 entry ID 幂等。生命周期或显式召回后续再次提交同一路线即可补齐部分失败，不需要补偿日志或 exactly-once 状态机。同一 session 只保留最新的未启动后台索引路线，显式同步优先于所有未启动后台轮次；显式搜索只共享尚未启动的调用后轮次，已经运行时每条路线最多保留一个后续轮次。调用取消或 5 秒等待到期后，协调器移除无人等待的待执行轮次，并取消无人等待的运行轮次，避免长会话后台路线和显式重试形成无界积压。

## 5. 验证与限制

验证覆盖跨 session 输入拒绝、非当前 branch 查询拒绝、损坏父链拒绝、来源展开、存储错误传播，以及调用后索引轮次的共享、后续 generation、后台路线折叠、显式轮次优先、超时取消和 shutdown。OpenViking候选过滤与结果边界由来源召回验证负责；本模块当前没有 Working Memory、迟到模型结果或上下文采用状态。
