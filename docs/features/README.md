# 功能规格

## 目录角色

本目录保存用户或任务模型可以观察到的当前功能语义，类别和生命周期服从 [`DOCUMENTION.md`](../../DOCUMENTION.md)。

## 功能规格

| 文档 | 当前责任 |
| --- | --- |
| [`session-recall.md`](session-recall.md) | 定义任务模型在当前 Pi session 和 branch 中按需找回早期来源的行为 |
| [`context-enhancement-state.md`](context-enhancement-state.md) | 定义自动上下文增强与 Pi 回退、原生压缩和状态标识的可观察行为 |
| [`memory-model-configuration.md`](memory-model-configuration.md) | 定义用户级记忆模型 JSONC、错误降级与项目 OpenViking 快速重启行为 |
