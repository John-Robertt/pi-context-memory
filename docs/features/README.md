# 功能规格

## 目录角色

本目录保存用户或任务模型可以观察到的当前目标功能语义，类别和生命周期服从 [`DOCUMENTION.md`](../../DOCUMENTION.md)。实现与证据状态由 [`../DEVELOPMENT.md`](../DEVELOPMENT.md) 维护。

## 功能规格

| 文档 | 当前责任 |
| --- | --- |
| [`session-recall.md`](session-recall.md) | 定义当前 Pi session 和 branch 中的来源搜索、权威展开与数据面故障行为 |
| [`context-enhancement-state.md`](context-enhancement-state.md) | 定义增强记忆独占工作上下文与自动压缩、复杂 current turn、运行状态和故障恢复 |
| [`memory-model-configuration.md`](memory-model-configuration.md) | 定义用户记忆模型 JSONC、实际能力状态、诊断与受管 OpenViking 重启 |
